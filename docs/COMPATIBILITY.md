# MineKB 360 - Compatibility

## Target
- Console: Xbox 360 RGH/JTAG
- Game: Minecraft Xbox 360 Edition
- Title ID: 584111F7
- Input: USB HID keyboard and mouse

## Planned Controls
- W: Move forward
- A: Move left
- S: Move backward
- D: Move right
- Space: Jump
- Shift: Crouch
- E: Inventory
- ESC: Pause
- Mouse: Camera
- Left click: Break blocks
- Right click: Place blocks

## Technical Base
- Research: X360Remap
- Plugin architecture: DashLaunch
- Configuration: To be adapted and tested

## Safety
Do not install unverified plugins.
Keep a backup of launch.ini.
Do not load X360Remap together with hiddriver360.
