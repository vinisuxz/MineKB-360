# MineKB 360 - Controls

## Keyboard
| Key | Action |
|---|---|
| W | Move forward |
| A | Move left |
| S | Move backward |
| D | Move right |
| SPACE | Jump |
| SHIFT | Crouch |
| E | Inventory |
| ESC | Pause |

## Mouse
| Button | Action |
|---|---|
| Movement | Camera |
| Left click | Break blocks |
| Right click | Place blocks |

## Planned Features
- Adjustable mouse sensitivity
- Configurable key mapping
- Minecraft profile
- USB keyboard and mouse support
